# Roadmap active

Les [milestones de Fusion](https://github.com/Silicium-Project/Fusion/milestones)
et les [issues ouvertes](https://github.com/Silicium-Project/Fusion/issues)
portent la roadmap active. Fusion reste privé sur décision du propriétaire ;
ces informations deviendront publiques seulement après une ouverture autorisée. Elles décrivent objectifs, dépendances natives,
critères d'acceptation et preuves attendues.

Les lots L0 à L6 de la refonte sont des tranches d'exécution des références
GOV-02/GOV-03, QRE et CI dans R0/R1. Ils ne remplacent pas ces références et
n'ajoutent pas de date de livraison non démontrée.

Le suivi interne du Project reste privé. Les arbitrages HOLD sont conservés
dans un espace privé jusqu'à une décision explicite ; ils ne sont pas assimilés
au backlog public ni considérés comme abandonnés.

Une PR fusionnée est en validation. Une livraison est terminée lorsque ses
critères et la preuve de sa cible ont été acceptés selon
[le workflow de contribution](../development/issue-workflow.md).
